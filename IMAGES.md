# Images needed — jeffschenck.com

The site is fully built and works right now with on-brand SVG placeholders.
When you send the real images, drop them in `assets/img/` with the **exact
filenames below** and they'll appear automatically (no code changes needed for
the ones marked "same name"). For the `.jpg` social images, just add the files.

All photos look best **dark / moody** — the design applies a subtle grayscale +
darken treatment on hover, so high-contrast, non-busy images work best.
